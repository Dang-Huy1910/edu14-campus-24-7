# Mã Nguồn Ứng Dụng – Campus 24/7

Thư mục này sẽ chứa toàn bộ mã nguồn chính của ứng dụng Campus 24/7 cho các Gate tiếp theo (Gate 2: Prototype & Gate 3: Final Product).

Dự kiến cấu trúc:
- `api/`: Backend service (FastAPI/Python) điều phối AI Agent, RAG và API database.
- `web/`: Frontend ứng dụng (Next.js/React hoặc Streamlit) cho Cổng Sinh viên & Dashboard Cán bộ.
- `rag/`: Vector DB indexing, chunking pipeline và semantic search.
